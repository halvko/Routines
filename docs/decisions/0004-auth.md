# 0004: Passkeys first, Argon2id password fallback, opaque session cookies

Accepted, 2026-11-06.

## Decision

- **Passkeys are the main way in.** The server stores only public keys.
- **A password is the fallback** for a new or lost device:
  - At least 15 characters, or 8 once the account also has a passkey;
    at least 128 allowed. No composition rules, no forced rotation
    (NIST SP 800-63B-4, final July 2025).
  - New passwords are checked against breached ones with the Have I Been
    Pwned range API (only a 5-character hash prefix leaves the server).
  - Stored with Argon2id at OWASP's baseline (19 MiB, 2 iterations,
    parallelism 1).
  - Per-account throttling with exponential backoff, well under NIST's
    100-attempt ceiling. Errors and timing do not reveal whether an account
    exists.
- **Sessions are opaque random tokens** in a `__Host-` cookie (`Secure`,
  `HttpOnly`, `SameSite=Lax`, `Path=/`), stored hashed on the server,
  regenerated at login, 30-day absolute lifetime, re-authentication before
  changing credentials. Logging out deletes the row. **No JWTs** for the app;
  the OAuth tokens Claude's connector needs are the only tokens, and they are
  bound to the MCP resource.
- **Reset** by an emailed, single-use, hashed token valid for 15–60 minutes,
  with the same response whether or not the account exists, and an offer to
  sign out everywhere.
- **Hand-rolled**, since it is one user and the surface is small enough to
  review in one sitting. Revisit with a library if other users or Google/Apple
  sign-in become real.

## Considered and not chosen

- **Hashing on the client** so the server never sees the password: naive
  client hashing makes the hash the password. Client-side stretching
  ("server relief") is non-standard and leaks which emails exist unless done
  carefully. OPAQUE (RFC 9807) is the principled version, but its only audit
  is of a 2021 release. Passkeys give the same property with less machinery.
- **Managed auth** (Clerk, Cognito, WorkOS): more lock-in than the code saved.

## Consequence for hosting

Argon2id at these settings takes roughly 40–70 ms of CPU, more than
Cloudflare's free plan allows per request; the budget allows a paid plan
(about $5/month).
